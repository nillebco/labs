Printing it

  • 3MF, multi-material (tool changer, MMU, AMS): one object with two parts, the plate on filament 1 and the code and text on filament 2. Open it in PrusaSlicer and check the two filament slots.
  • One extruder: use “STL for colour change” and add a colour change at the height shown above (the + on PrusaSlicer's layer slider). Start with the plate colour.
  • Print face up on a smooth sheet. A 0.4 mm nozzle handles QR modules from about 1.2 mm; the chip above tells you the size of yours.
  • The scan check reads the code straight from the model geometry. Once printed, matte filament and good contrast scan best; a glossy black on white can glare under a ceiling light.
