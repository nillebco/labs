Pressto

Pagecast makes a web page searchable: press ⌥. and type what you want. Pressto asks the same of the whole desktop: press ⇧⌘H in any app, type a few letters, and press ↵. It started as a fork of Scoot, a BSD-3 keyboard cursor actuator.

⇧⌘H open→ ⌨️ type→ 🎯 rank→ ↵ press

What it does

  • One list, four groups, like Pagecast: Quick actions (copy the page address, as Markdown, or its title), Window (the focused window's buttons, links and fields), Tabs and Menu (every menu bar item). Empty query shows each group; typing ranks them together.
  • Scopes narrow the search: > actions, # window, @ tabs, / menu — or as words, tab: azure pull.
  • Tabs by address, not just title. A tab called “Overview” whose URL holds sfp-rag-dev is found by typing sfprag. For Zen and Firefox the addresses come from the browser's own session store.
  • Presses, not clicks. Rows run AXPress on the element itself, so it works on controls hidden behind others and on system sheets — a Safari camera prompt included.
  • Opens over the window you are using, on its display, not wherever the mouse happens to be. Menu items show instantly; the window scan fills in behind them.
  • Scoot's grid and hint-label modes are still there, now with a grid that resizes from 30 to 200 pt without crashing.

The matcher

Pagecast's ranking had a known flaw: with “Complete” and “Complete merge” both listed, typing cplmrg still put “Complete” first. Pressto's matcher picks the best placement of the query in each candidate rather than the first one — a small dynamic program — and rewards consecutive runs above word starts. cplmrg now lands on “Complete merge”, and a tight run inside a URL beats letters scattered across a title. Pure Swift, no AppKit, 58 tests in the project.

What building it taught

  • Zen lists every workspace's tabs at once. Inactive workspaces are parked sideways, off the left edge; the active one overflows vertically. Clipping horizontally against each ancestor, and allowing vertical overflow only inside a tab group, keeps exactly the tabs you can scroll to — and cut the scan from ~750 ms to a fraction of that.
  • Firefox-family tabs carry no URL in the accessibility tree, only a title. The session store does: recovery.jsonlz4, Mozilla's LZ4 wrapper around JSON, decoded in about 50 ms for 270 tabs and cached by modification date.
  • The page itself was invisible to the library. AXSwift maps roles to an enum without AXWebArea, so the web area came back with no role and the page commands never appeared. Reading the role as a plain string fixed it.
  • Firefox keeps its tree shut until asked. With AXEnhancedUserInterface off, Zen exposes 6 nodes; with it on, 1674 — after about two seconds of waking up.
  • A grid crash from floating point. Building cells with a fractional stride produced 60 rectangles for 55 cells at some sizes; an assertion caught the mismatch. Cells are now built by index, with a test over every screen and cell size.
  • Stacked buttons lost their labels. Hint labels for buttons a few points apart were merged as “crowded”, hiding one of Safari's three permission buttons. The padding is now 2 pt, not 10.

Why fork Scoot

  • The alternatives are closed. Shortcat, Homerow and Paletro are free-but-closed or commercial; the open projects, Vimac (GPL-3.0, dead since 2022) and Scoot (BSD-3, maintained), do hint labels and a grid, not search.
  • Scoot already had the hard parts: overlays across every display and Space, click synthesis, a menu bar agent, global hotkeys. Everything except the query.
  • BSD-3 keeps the options open for a signed public release. The new name is so Pressto never passes for Scoot, or for its author's endorsement; Michael Russo's copyright notice stays in the source and the app.

What is next

  • Tab addresses for Safari and Chromium browsers.
  • A first-run screen that explains the Accessibility permission before asking for it.
  • A signed, notarized download with automatic updates. Not the App Store: its sandbox forbids driving other apps' interfaces, which is the whole point.
  • Commands keyed by app, the piece Pagecast has and none of the Mac tools do.

Status, honestly

Used daily, not yet released: no download, and the code still carries the Scoot name. Source on GitHub, forked from mjrusso/scoot under BSD-3-Clause.
